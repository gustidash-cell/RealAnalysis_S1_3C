# RealAnalysis_S1_3C (Analisis Riil - Bab 1: Pembuktian 3 Kolom)

Aplikasi Interaktif Media Pembelajaran Analisis Riil berbasis HTML/CSS/JS modern dengan fitur **Pembuktian 3 Kolom**, **Reorder Mode (Susun Ulang Bukti)**, **Practice Mode (Latihan Mandiri)**, **Sistem Clue/Hint Budget**, dan **Hero Final Score**.

## 🌟 Fitur Utama
- **Susun Ulang Bukti (Reorder Mode)**: Latihan interaktif menyusun langkah-langkah pembuktian matematika secara intuitif.
- **Latihan Mandiri (Practice Mode)**: Menuliskan premis dan alasan pembuktian secara mandiri.
- **Sistem Clue & Hint**: Bantuan interaktif dengan kuota clue.
- **Visual & UI Modern**: Tampilan dengan Dark/Light mode toggle, tipografi matematika jernih, dan visualisasi skor akhir.
- **Retensi Progres**: Menyiapkan penyimpanan status dan nilai progres latihan.
